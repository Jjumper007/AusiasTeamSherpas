Guardia de cifras #4

La garantía de que el vídeo no inventa números. Un único sitio convierte un fact en texto (fmt) y un único sitio comprueba que todo número escrito sale de ahí (validate*).

El módulo

Interfaz
  • fmt.round(x) → "$1.4M" · fmt.currency(x) → "$1,427,456" · fmt.percent(x) → "49%"
  • fmt.years(x) → "17 years" · fmt.fact(fact) → formato según su unit
  • validateNarration(text, facts) → { ok, errors[] }
  • validateTsx(source, facts) → { ok, errors[] }
Implementación que esconde (9 archivos, ~860 líneas)
tokens: encuentra números y escalas accepted: formas válidas de cada fact tsx-scan: escáner de TSX tsx-structural: qué es estructural errors: línea, columna, fact más cercano
Los validadores nunca lanzan: devuelven los errores como datos. fmt no usa APIs de Node ni Intl, así que funciona igual en el backend, en Remotion y en el navegador.

Por qué no pueden desincronizarse

Las formas aceptadas de cada fact se calculan ejecutando fmt y leyendo lo que imprime. Si mañana fmt.round pasa a escribir "$1.43M", el validador lo acepta automáticamente y rechaza "$1.4M". Cambiar el formato es tocar un único archivo.

Number "$1.5M" at line 2, column 24 does not come from facts.
Nearest fact: RETIREMENT_GAP = 1427455.89 (usd). Write it as "$1.4M" or "$1,427,456".
Context: "Your retirement gap is $1.5M today."

Límites conocidos

  • Se cuela un número inventado que llega por una constante o una prop numérica: const GAP = 1500000; fmt.round(GAP). Cerrarlo exige que los argumentos de fmt sean constantes importadas de facts.ts; relevante para #9.
  • Se cuelan números escritos con letras, cifras de 1–2 dígitos inventadas y confusiones de unidad ("$2,044").
  • Se rechazan números legítimos de 3+ dígitos que no son facts ("529 plan") y las cifras que solo están en la prosa del brief. Lo segundo es intencionado.
  • El escáner de TSX es heurístico, no un parser.

Decisión abierta: 100 se acepta siempre para que pase "52 out of 100", pero también deja pasar un "$100" o un "100%" inventado. La alternativa es un fact SCORE_MAX.
