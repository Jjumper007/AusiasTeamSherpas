Plantilla de vídeo #3

Proyecto Remotion con una sola composición, SherpasVideo. Recibe un VideoProps y produce un MP4 de 1920×1080 a 30 fps. Es a la vez el vídeo de respaldo y la base que Claude modificará en #9.

El aspecto visual es un placeholder. Paleta, ilustración y tipografía se rehacen con las reglas de diseño del equipo. La estructura de esta página no cambia con eso.

El módulo, visto desde fuera

Interfaz
  • remotion render src/index.ts SherpasVideo out.mp4 --props=video-props.json
  • props: VideoProps (se validan con VideoPropsSchema al empezar)
  • duración total = suma de scenes[i].durationSec

El seam donde se enchufan las escenas

Video.tsx no conoce ninguna escena concreta: busca el componente en el mapa SCENES y le pasa siempre los mismos props. Ese mapa es el seam entre la parte bloqueada y la editable.

// src/scenes/types.ts
interface SceneProps {
  brief: Brief
  facts: Facts
  scene: Scene            // narration, visualIdea, factsUsed
  chapter: Chapter
  durationInFrames: number
}

// src/scenes/index.ts
const SCENES: Record<Part, FC<SceneProps>>

Reglas que cumple toda escena

  • Solo muestra cifras de scene.factsUsed, a través de sceneFacts / pointsFacts y siempre formateadas con fmt. Ninguna cifra escrita a mano: validateTsx da por buenos los 14 archivos TSX.
  • Toma colores, fuentes y márgenes de tokens.ts. Cambiar el estilo es cambiar ese archivo.
  • La parte 3 cambia con explainLevel: una cifra grande (simple), hasta 3 filas (straight) o la tabla con cifra exacta y redondeada (nerd).
  • Si a una escena le faltan los facts que necesita, enseña el texto del capítulo en vez de un número.
